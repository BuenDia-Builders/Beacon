**v0.1 — MVP.** The core matcher works end to end today: 9 passing tests,
zero runtime dependencies, validated against three real Stellar codebases
(not synthetic examples — see [Why](/Beacon/why/)).

<CardGrid>
	<Card title="No server" icon="rocket">
		`npm install @buendia-builders/beacon`, then call `match()`. No index to
		build, no process to run.
	</Card>
	<Card title="Zero dependencies" icon="seti:lock">
		Levenshtein distance and token overlap are ~90 lines of plain TypeScript.
		Nothing to audit in `node_modules`.
	</Card>
	<Card title="Typo-tolerant" icon="magnifier">
		Catches reordered words, extra context, and a typo inside a reference
		code — the memo problem anchors keep re-solving from scratch.
	</Card>
	<Card title="Honestly scoped" icon="warning">
		Read [Limitations](/Beacon/guide/limitations/) before using this for real
		money — it is not safe for every memo shape.
	</Card>
</CardGrid>
